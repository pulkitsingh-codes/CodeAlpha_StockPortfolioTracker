# Stock Portfolio Tracker using Python

## About the Project
This is a beginner-friendly Python console application that calculates the total investment value of selected stocks.

The program uses predefined stock prices and allows users to enter stock names and quantities.

## Features
- Displays available stocks and their prices.
- Takes stock names and quantities from users.
- Calculates individual stock investment values.
- Calculates total portfolio investment.
- Saves the investment summary in a text file.

## Technologies Used
- Python

## Concepts Used
- Dictionaries
- Variables
- For Loops
- If-Else Statements
- User Input and Output
- File Handling

## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python stock_tracker.py
```

## Note
The stock prices used in this project are predefined sample values and are not live market prices.
